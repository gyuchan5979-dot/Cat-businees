# 자동화 파이프라인 설계 (초안)

목표: 노트북 하나로, 하루 30분 이내 관리로 돌아가는 위탁판매 스토어.
원칙: 소수 정예(초기 20~50개 상품), 사람은 "승인"만 하고 나머지는 자동.

## 전체 흐름

```
[1 상품 소싱]  도매몰 상품DB (펫러브 엑셀/CSV)
      ↓  카테고리·키워드·마진 필터
[2 콘텐츠 생성]  Claude API → 상품명 · 태그 · 상세페이지(HTML)
      ↓  내가 검토·승인 (유일한 수작업)
[3 상품 등록]  네이버 커머스API → 스마트스토어 등록
      ↓
[4 주문 처리]  커머스API 신규주문 조회 → 도매몰 발주 → 송장번호 입력
      ↓
[5 CS]  문의 수집 → Claude 답변 초안 → 승인 후 발송
      ↓
[6 모니터링]  품절·가격 변동 동기화, 일일 리포트
```

## 단계별 상세

### 1. 상품 소싱
- 입력: 펫러브 상품DB 다운로드 (상품코드, 상품명, 공급가, 권장소비자가, 이미지, 옵션, 재고)
- 필터 규칙
  - 카테고리: 계단·스텝·매트·식기·화장실·발판·방석·캣타워
  - 제외: 전기 제품(KC 인증서 없는 것), 사료·영양제, "가격준수" 상품 중 마진 안 나오는 것
  - 마진: (판매가 − 공급가 − 배송비 − 네이버 수수료 약 5~6%) ≥ 25%
- 출력: 후보 상품 목록 (CSV)

### 2. 콘텐츠 생성 (Claude API)
- 상품명: `[검색 키워드] + [핵심 스펙] + [노령묘 효익]` 50자 이내
  - 키워드는 `docs/키워드_1차분석.md`의 실제 검색어 사용 (노령묘 용품 X → 고양이 계단 O)
- 상세페이지 구성 (노령묘 전문 스토어 톤)
  1. 이런 변화가 보이나요? (점프 망설임, 화장실 실수 등 노화 신호)
  2. 왜 이 제품인가 (높이·각도·미끄럼방지 등 근거)
  3. 사용 장면 / 사이즈 가이드
  4. 함께 쓰면 좋은 세트
- 이미지: 도매몰 제공 이미지 사용 (저작권 사용 허락 범위 확인)
- 승인 단계: 생성 결과를 한 화면에서 보고 승인/수정

### 3. 상품 등록 — 네이버 커머스API
- 준비: 스마트스토어 판매자 가입 → 커머스API센터(apicenter.commerce.naver.com)에서 애플리케이션 등록
- 인증: client_id + client_secret → bcrypt 서명 → OAuth 토큰
- 상품 등록 API로 원상품 등록, 이미지는 이미지 업로드 API 먼저 호출
- 등록 한도: 판매 실적 기반 → 소수 정예 전략과 맞음

### 4. 주문 처리
- 10~30분 간격으로 신규 주문(결제완료) 조회 → 발주확인 처리
- 도매몰 발주: 대부분 API 없음 → 방법
  - A. 도매몰 "엑셀 일괄 발주" 양식으로 자동 변환 후 하루 1~2회 업로드 (가장 현실적)
  - B. 브라우저 자동화(Playwright)로 발주 (도매몰 약관 확인 필요)
- 송장번호: 도매몰 배송 조회 → 커머스API 발송처리
- 오케스트레이션: Make(이미 연결됨) 시나리오 또는 GitHub Actions 스케줄로 실행

### 5. CS
- 상품 문의 / 고객 문의 API로 수집 → Claude가 답변 초안 (배송·사이즈·사용법은 FAQ 기반)
- 초기에는 전부 승인 후 발송, 패턴이 쌓이면 단순 문의만 자동 발송

### 6. 모니터링
- 하루 1회: 도매몰 품절·가격 → 스마트스토어 재고·가격 동기화 (품절 상품 판매 방지가 최우선)
- 일일 리포트: 주문 수, 매출, 미처리 주문, 미답변 문의 → 휴대폰 알림

## 구현 순서 (제안)
1. 키워드 검증 완료 (API 키 필요)
2. 펫러브 위탁회원 가입 → 상품DB 샘플 확보 → 1단계 필터 스크립트
3. 2단계 콘텐츠 생성 스크립트 → 상품 5개로 시험
4. 스마트스토어 개설 + 커머스API 등록 → 3단계 자동 등록
5. 첫 주문 들어오면 4단계 자동화 (처음 몇 건은 수동으로 흐름 파악)
6. 5·6단계

## 사장님이 해야 하는 것 (자동화 불가)
- 네이버 검색광고 / 개발자센터 API 키 발급
- 펫러브 위탁회원 가입, 상품DB 다운로드 권한 확인
- 스마트스토어 판매자 가입 (사업자등록증, 통신판매업 신고 필요)
- 커머스API센터 애플리케이션 등록
