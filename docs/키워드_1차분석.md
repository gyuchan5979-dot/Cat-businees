# 키워드 1차 분석 — 네이버 자동완성 (2026-10-24)

API 키 없이 네이버 자동완성으로 수요를 먼저 확인했다. 자동완성은 검색이 많은 순서로 노출되므로
"자동완성이 깊다 = 사람들이 실제로 그 말로 검색한다"는 신호다. 정확한 검색량·상품 수는
API 키 발급 후 `scripts/keyword_competition.py`로 확인한다.

원본: `data/autocomplete_keywords.csv` (재실행: `python3 scripts/autocomplete_keywords.py`)

## 핵심 발견

1. **"노령묘 용품", "노령묘 케어"는 자동완성이 없다.** 사람들이 이 말로 검색하지 않는다.
   → "노령묘 전문"은 브랜드·스토어 정체성으로 쓰고, 상품명은 실제 검색어(고양이 계단, 고양이 화장실 발판 등)로 잡는다.
   예: `고양이 계단 3단 노령묘 관절 보호 미끄럼방지`

2. **보호자가 "노령묘/노묘"와 함께 찾는 것은 사료·영양제·캣타워·화장실·간식.**
   - 사료·영양제·간식: 초기 제외 품목(규제) → 대신 정보 콘텐츠 주제로 활용 (유입용)
   - **노령묘/노묘 캣타워**: 두 시드 모두에서 등장 → 낮은 캣타워·계단형 캣타워를 상품군에 추가할 가치가 큼
   - **노령묘 화장실**: 등장 → 입구 낮은 화장실 수요 확인

3. **이동 보조 수요가 가장 뚜렷하다.**
   - `고양이 계단`: 자동완성 10개 꽉 참 (스크래처, 캣타워, 숨숨집, 슬라이드, 대형, 1단 등) → 수요 큼, 경쟁도 클 가능성
   - `고양이 침대 계단`, `고양이 미끄럼방지 매트`: 자동완성 있음 → 틈새로 유망
   - `고양이 계단 숨숨집`, `고양이 계단 슬라이드`: 세부 니치 후보

4. **화장실 발판 수요가 생각보다 크다.**
   - `고양이 화장실 발판`: 계단·패드·소형까지 세분화 → `고양이 화장실 발판 계단`은 노령묘 포지셔닝과 딱 맞음

5. **정수기는 수요가 크지만 대부분 전기 제품(모터·펌프)** → KC 인증 이슈. 초기 제외 유지. 필터 등 소모품만 검토.

6. **자동완성 없는 키워드** (수요 작거나 표현이 다름):
   노령묘 계단, 고양이 높은 식기, 노령묘 식기, 수염 스트레스 식기, 낮은 고양이 화장실,
   노령묘 방석, 고양이 관절 쿠션, 고양이 메모리폼 방석, 고양이 보온 하우스
   → 휴식 카테고리는 "고양이 방석", "고양이 쿠션", "고양이 숨숨집" 같은 일반어로 다시 확인 필요.

## 1차 상품 후보 (검색량 확인 전 가설)

| 우선순위 | 상품 | 근거 키워드 |
|---|---|---|
| 1 | 고양이 계단 (2~3단, 미끄럼방지) | 고양이 계단, 고양이 침대 계단 |
| 2 | 고양이 화장실 발판 계단 | 고양이 화장실 발판 계단 |
| 3 | 낮은 캣타워 / 계단형 캣타워 | 노령묘 캣타워, 노묘 캣타워, 고양이 계단 캣타워 |
| 4 | 고양이 미끄럼방지 매트 | 고양이 미끄럼방지 매트 |
| 5 | 입구 낮은 화장실 | 노령묘 화장실 |
| 보조 | 식기 받침대 (높은 식기) | 고양이 식기 받침대 |

상황별 세트 아이디어:
- **"관절 약해진 우리 아이" 세트**: 침대 계단 + 미끄럼방지 매트
- **"화장실 실수 시작" 세트**: 입구 낮은 화장실 + 화장실 발판 계단 + 배변패드
